# 证据来源评估优化总结

## 📋 优化概述

本次优化对 `claw_map` 项目的证据来源评估进行了全面升级，通过增加证据来源可靠性、权威性和代表性评估，提升了证据来源评估的准确性。

## 🎯 优化内容

### 1. 证据来源评估算法

#### 来源可靠性评估
- **身份证据**：小红书号、IP属地、简介 → 0.9
- **生育证据**：备孕、怀孕、宝宝、育儿 → 0.9
- **空间证据**：地铁、公园、医院、学校 → 0.9
- **消费证据**：奢侈、高端、平价、省钱 → 0.9
- **年龄证据**：大学、工作、备孕、怀孕、宝宝 → 0.9

#### 来源权威性评估
- **证据长度**：50字以上 +0.1，100字以上 +0.1
- **证据来源**：根据特征类型调整
- **证据一致性**：检查矛盾信息

#### 来源代表性评估
- **相关性评估**：根据特征类型评估证据相关性
- **时效性评估**：检查时间关键词评估证据时效性
- **可信度评估**：评估证据长度、来源和一致性

### 2. 特征值结构优化

#### 新增证据来源字段
```python
{
    "value": {...},
    "evidence": [...],
    "stats": {...},
    "is_fallback": False,
    "confidence": 0.85,
    "evidence_quality": {  # 新增
        "relevance": 0.9,
        "timeliness": 0.7,
        "credibility": 0.8,
        "overall": 0.8,
    },
}
```

### 3. 整体证据来源计算（新增）

#### 计算公式
```python
overall = (relevance + timeliness + credibility) / 3
```

#### 各维度平均质量
- **相关性**：所有特征的相关性平均值
- **时效性**：所有特征的时效性平均值
- **可信度**：所有特征的可信度平均值

### 4. 证据一致性检查（新增）

#### 矛盾信息检测
- **生育相关**：同时包含正面和负面关键词
- **生活阶段**：同时包含单身和已婚关键词

#### 一致性评估
- **一致**：可信度 +0.1
- **不一致**：可信度不变
