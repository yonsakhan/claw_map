# 推断准确度优化总结

## 📋 优化概述

本次优化对 `claw_map` 项目的推断准确度进行了全面升级，通过优化 Prompt 模板和特征提取算法，提升了生育意愿推断的准确性。

## 🎯 优化内容

### 1. Prompt 模板优化

#### 新增推断规则
- **年龄段推断**：结合多个证据进行交叉验证
- **生育状态推断**：按优先级排序，区分强弱信号
- **收入水平推断**：需要多个信号交叉验证
- **空间偏好推断**：基于实际需求场景
- **生育意愿评分**：必须有明确证据支持

#### 质量控制规则
1. **证据优先**：每个推断必须有至少1个证据片段支持
2. **交叉验证**：年龄与生育状态必须逻辑一致
3. **置信度标注**：对不确定的推断降低置信度
4. **避免臆测**：如果证据不足，填写"Unknown"
5. **保持简洁**：reasoning_summary 用一句话概括

### 2. 特征提取算法优化

#### 新增特征维度
- **年龄段识别**：18-24/25-29/30-34/35-39/40+
- **生育意愿识别**：正面/负面/中性/未知 + 评分(0-5)

#### 关键词库扩展
- **生育相关**：约80个关键词
- **空间偏好**：约70个关键词
- **收入水平**：约30个关键词
- **年龄段**：约20个关键词
- **生育意愿**：约20个关键词

### 3. PersonaExtractor 优化

#### 输出格式标准化
- 新增 `confidence` 字段：置信度评估
- 新增 `evidence_summary` 字段：证据摘要
- 优化 `_normalize_output` 方法：确保所有字段都存在

#### Mock 模式优化
- 基于特征画像生成更准确的模拟结果
- 根据生育状态调整评分
- 构建证据摘要

## 🔍 问题分析

### 1. 丁克一族推断失败原因

#### 年龄段推断失败
- **原因**：特征画像中没有明显的年龄段关键词
- **改进**：增加更多年龄段相关关键词，如"30岁"、"中年"等

#### 生育状态推断失败
- **原因**：关键词匹配优先级问题
  * "二人世界"被匹配为"已婚未育"
  * 但实际应该是"未婚"
- **改进**：优化关键词优先级，增加"未婚"的强信号

#### 空间偏好推断失败
- **原因**：关键词匹配问题
  * "旅行"被匹配为"生活配套"
  * 但实际应该是"公园绿地"
- **改进**：优化空间偏好关键词库

### 2. 怀孕记录推断偏差

#### 空间偏好推断偏差
- **原因**：额外推断了"生活配套"
- **改进**：优化空间偏好推断逻辑，减少误推断

## 🚀 改进方案

### 1. 优化关键词库

#### 年龄段关键词
- 增加"30岁"、"中年"、"80后"、"90后"等关键词
- 增加"结婚"、"买房"等生活阶段关键词

#### 生育状态关键词
- 优化"未婚"的强信号
- 增加"单身"、"一个人"等关键词
- 降低"二人世界"的优先级

#### 空间偏好关键词
- 优化"旅行"的匹配逻辑
- 增加"户外"、"自然"等关键词
- 减少误匹配

### 2. 优化推断逻辑

#### 交叉验证
- 年龄与生育状态必须逻辑一致
- 空间偏好与生活阶段必须匹配
- 收入水平与消费习惯必须一致

#### 置信度评估
- 根据证据强度评估置信度
- 对不确定的推断降低置信度
- 提供置信度阈值

### 3. 增加人工审核

#### 自动标记
- 对置信度低于 0.7 的推断进行标记
- 对矛盾推断进行标记
- 对异常推断进行标记

#### 人工审核
- 提供审核界面
- 支持人工修正
- 记录修正历史
