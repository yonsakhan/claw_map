# 证据质量评估优化总结

## 📋 优化概述

本次优化对 `claw_map` 项目的证据质量评估进行了全面升级，通过增加证据相关性、时效性和可信度评估，提升了证据质量评估的准确性。

## 🎯 优化内容

### 1. 证据质量评估算法

#### 相关性评估
- **生育相关证据**：备孕、怀孕、宝宝、孩子、育儿 → 0.9
- **生活阶段证据**：单身、结婚、已婚、未婚 → 0.9
- **空间偏好证据**：地铁、通勤、公园、医院、学校 → 0.9
- **消费水平证据**：奢侈、高端、平价、省钱 → 0.9
- **年龄段证据**：大学、工作、备孕、怀孕、宝宝 → 0.9

#### 时效性评估
- **时间关键词**：今天、昨天、最近、刚刚、现在 → 0.9
- **近期关键词**：本月、今年、这周、上周、上个月 → 0.7
- **过去关键词**：去年、前年、以前、过去 → 0.3

#### 可信度评估
- **证据长度**：50字以上 +0.1，100字以上 +0.1
- **证据来源**：根据特征类型调整
- **证据一致性**：检查矛盾信息

### 2. 特征值结构优化

#### 新增证据质量字段
```python
{
    "value": {...},
    "evidence": [...],
    "stats": {...},
    "is_fallback": False,
    "confidence": 0.85,
    "evidence_quality": {  # 新增
        "relevance": 0.9,
        "timeliness": 0.7,
        "credibility": 0.8,
        "overall": 0.8,
    },
}
```

### 3. 整体证据质量计算（新增）

#### 计算公式
```python
overall = (relevance + timeliness + credibility) / 3
```

#### 各维度平均质量
- **相关性**：所有特征的相关性平均值
- **时效性**：所有特征的时效性平均值
- **可信度**：所有特征的可信度平均值

### 4. 证据一致性检查（新增）

#### 矛盾信息检测
- **生育相关**：同时包含正面和负面关键词
- **生活阶段**：同时包含单身和已婚关键词

#### 一致性评估
- **一致**：可信度 +0.1
- **不一致**：可信度不变
