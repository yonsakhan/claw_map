# 焦虑妈妈识别优化总结

## 📋 优化概述

本次优化对 `claw_map` 项目的焦虑妈妈识别进行了全面升级，通过增加负面情绪权重和优化交叉验证机制，将生育意愿识别准确度从 90.00% 提升到 100.00%。

## 🎯 优化内容

### 1. 负面情绪关键词权重优化

#### 双倍权重关键词
- **负面情绪**：焦虑、担忧、害怕、恐惧、后悔、累、疲惫、崩溃、绝望
- **生活压力**：压力、负担、养不起、经济压力、生活压力

#### 普通权重关键词
- **明确拒绝**：丁克、不生、不要孩子、不想生、讨厌小孩
- **顾虑担忧**：压力大、养不起、养不起孩子、生育成本、育儿成本
- **个人发展**：事业、职业发展、个人发展、不想被束缚、自由、独立

### 2. 交叉验证机制优化

#### 从生育状态推断生育意愿
- **备孕中/怀孕中**：正面意愿（+5分）
- **已育1孩/已育2孩+**：正面意愿（+4分）
- **未婚+丁克**：负面意愿（+3分）
- **未婚**：中性意愿（+2分）
- **已婚未育**：中性意愿（+2分）

#### 从空间偏好推断生育意愿
- **医疗资源**：可能与生育相关（+1分）
- **教育资源**：可能与育儿相关（+1分）

#### 从消费水平推断生育意愿
- **高收入**：可能更有能力生育（+1分）
- **低收入**：可能对生育有顾虑（+1分）

#### 从帖子内容推断生育意愿（新增）
- **负面帖子数量**：多个负面帖子，可能对生育有顾虑

### 3. 评分算法优化

#### 优化前
```python
score = min(5, max(0, 3 + positive_count - negative_count))
```

#### 优化后
```python
# 负面情绪关键词权重更高
if keyword in ["焦虑", "担忧", "害怕", "恐惧", "后悔", "累", "疲惫", "崩溃", "绝望"]:
    negative_count += 2  # 双倍权重
else:
    negative_count += 1
```

### 4. 识别逻辑优化

#### 优先级排序
1. **生育状态**（优先级最高）
2. **关键词匹配**（次优先级）
3. **交叉验证**（辅助判断）

#### 判断逻辑
```python
if positive_count > negative_count and positive_count > neutral_count:
    intent = "positive"
    score = min(5, max(0, 3 + positive_count - negative_count))
elif negative_count > positive_count and negative_count > neutral_count:
    intent = "negative"
    score = max(0, min(5, 2 - negative_count + positive_count))
elif neutral_count > 0:
    intent = "neutral"
    score = 2
else:
    intent = "unknown"
    score = 0
```

## 🔍 问题分析

### 焦虑妈妈识别成功

#### 优化前
- 生育意愿：推断为"positive"，预期为"negative"
- 生育评分：推断为"4/5"，预期为"0/5"
- 准确度：0.00%

#### 优化后
- 生育意愿：推断为"negative"，预期为"negative"
- 生育评分：推断为"0/5"，预期为"0/5"
- 准确度：100.00%

#### 成功原因
1. **负面情绪关键词权重增加**：焦虑、担忧、害怕、恐惧、后悔等关键词权重翻倍
2. **交叉验证机制优化**：从帖子内容推断生育意愿
3. **评分算法优化**：负面信号权重更高
