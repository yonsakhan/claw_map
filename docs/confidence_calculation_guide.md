# 置信度计算优化总结

## 📋 优化概述

本次优化对 `claw_map` 项目的置信度计算进行了全面升级，通过增加置信度评估机制和优化计算算法，提升了置信度计算的准确性。

## 🎯 优化内容

### 1. 置信度计算算法优化

#### 关键词匹配置信度
- **生育相关关键词**：基础置信度 0.9
- **生活阶段关键词**：基础置信度 0.8
- **年龄段关键词**：基础置信度 0.7

#### 证据数量调整
- **3个以上证据**：置信度 +0.1
- **2个证据**：置信度 +0.05

### 2. 空间偏好置信度优化

#### 匹配数量调整
- **3个以上匹配**：置信度 +0.2
- **2个匹配**：置信度 +0.1

#### 证据数量调整
- **6个以上证据**：置信度 +0.1
- **4个证据**：置信度 +0.05

### 3. 生育意愿置信度优化

#### 信号强度调整
- **10个以上信号**：置信度 +0.3
- **5个以上信号**：置信度 +0.2
- **3个以上信号**：置信度 +0.1

#### 信号差异调整
- **正面信号 > 负面信号 * 2**：置信度 +0.2
- **正面信号 > 负面信号 * 1.5**：置信度 +0.1
- **负面信号 > 正面信号 * 2**：置信度 +0.2
- **负面信号 > 正面信号 * 1.5**：置信度 +0.1

### 4. 整体置信度计算（新增）

#### 加权平均置信度
- **身份特征**：权重 1.0
- **生活阶段**：权重 1.5
- **空间偏好**：权重 1.0
- **消费水平**：权重 1.0
- **活跃度**：权重 0.5
- **年龄段**：权重 1.0
- **生育意愿**：权重 1.5

#### 计算公式
```python
weighted_sum = sum(c * w for c, w in zip(valid_confidences, weights))
total_weight = sum(weights)
overall_confidence = weighted_sum / total_weight
```

### 5. 特征值结构优化

#### 新增置信度字段
```python
{
    "value": {...},
    "evidence": [...],
    "stats": {...},
    "is_fallback": False,
    "confidence": 0.85,  # 新增
}
```
