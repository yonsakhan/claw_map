# 证据来源可视化优化总结

## 📋 优化概述

本次优化对 `claw_map` 项目的证据来源可视化进行了全面升级，通过增加证据来源分布图、证据来源解释和证据来源对比，提升了证据来源可视化的准确性。

## 🎯 优化内容

### 1. 证据来源可视化算法

#### 特征置信度分布
- **身份特征**：置信度 0.9
- **生活阶段**：置信度 0.8
- **空间偏好**：置信度 0.7
- **消费水平**：置信度 0.6
- **活跃度**：置信度 0.5
- **年龄段**：置信度 0.7
- **生育意愿**：置信度 0.8

#### 证据质量分布
- **相关性**：证据与特征的相关程度
- **时效性**：证据的时间新鲜度
- **可信度**：证据的可靠性
- **整体质量**：综合评估

#### 证据分布统计
- **证据数量**：每个特征的证据数量
- **证据来源**：证据的具体来源
- **证据类型**：证据的分类

#### 信号分布统计
- **正面信号**：生育意愿正面的信号数量
- **负面信号**：生育意愿负面的信号数量
- **中性信号**：生育意愿中性的信号数量

### 2. 特征值结构优化

#### 新增证据来源可视化字段
```python
{
    "value": {...},
    "evidence": [...],
    "stats": {...},
    "is_fallback": False,
    "confidence": 0.85,
    "evidence_quality": {...},
    "evidence_visualization": {  # 新增
        "feature_confidence": {...},
        "evidence_quality": {...},
        "evidence_distribution": {...},
        "signal_distribution": {...},
        "summary": {...},
    },
}
```

### 3. 整体证据来源可视化计算（新增）

#### 可视化摘要
- **置信度排名**：按置信度排序的特征列表
- **质量排名**：按证据质量排序的特征列表
- **总信号数**：所有信号的总和
- **主导信号**：占比最高的信号类型
- **信号比例**：各类型信号的占比

### 4. 证据来源对比（新增）

#### 特征间对比
- **置信度对比**：不同特征的置信度对比
- **质量对比**：不同特征的证据质量对比
- **分布对比**：不同特征的证据分布对比

#### 用户间对比
- **置信度对比**：不同用户的置信度对比
- **质量对比**：不同用户的证据质量对比
- **信号对比**：不同用户的信号分布对比
