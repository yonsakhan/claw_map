# 特征提取算法优化总结

## 📋 优化概述

本次优化对 `claw_map` 项目的特征提取算法进行了全面升级，新增了多个维度的识别能力。

## 🎯 优化内容

### 1. 新增特征维度

| 特征维度 | 说明 | 识别能力 |
|---------|------|---------|
| 生活阶段 | 未婚/已婚未育/备孕中/怀孕中/已育1孩/已育2孩+ | ✅ |
| 空间偏好 | 通勤便利/公园绿地/医疗资源/教育资源/生活配套/出行安全/居住空间 | ✅ |
| 收入水平 | 高/中/低 | ✅ |
| 年龄段 | 18-24/25-29/30-34/35-39/40+ | ✅ |
| 生育意愿 | 正面/负面/中性/未知 + 评分(0-5) | ✅ |

### 2. 关键词库扩展

#### 生育相关关键词
- **备孕中**：备孕、排卵、验孕、造人、排卵试纸、基础体温、叶酸等
- **怀孕中**：怀孕、孕检、产检、胎动、孕吐、NT检查、唐筛、四维等
- **已育1孩**：宝宝、婴儿、奶粉、辅食、月子、育儿、带娃、遛娃等
- **已育2孩+**：大宝、二宝、三宝、俩娃、二胎、三胎、双胞胎等

#### 空间偏好关键词
- **通勤便利**：地铁、通勤、上班、挤地铁、公交、打车等
- **公园绿地**：公园、遛娃、户外、绿地、散步、跑步等
- **医疗资源**：医院、产检、儿科、看病、挂号、妇幼保健院等
- **教育资源**：学校、幼儿园、学区、托班、早教、培训班等
- **生活配套**：超市、商场、买菜、生活、便利店、菜市场等
- **出行安全**：安全、夜路、人少、治安、监控、路灯等
- **居住空间**：房子、户型、面积、搬家、租房、买房等

#### 收入水平关键词
- **高**：奢侈、高端、五星、名牌、豪华、私立医院、月子中心等
- **低**：平价、省钱、优惠、折扣、团购、打折、促销等

#### 年龄段关键词
- **18-24**：大学、考研、应届、实习、毕业、校园等
- **25-29**：工作、职场、加班、升职、跳槽、租房等
- **30-34**：备孕、怀孕、宝宝、育儿、家庭、事业等
- **35-39**：二胎、高龄、35岁、中年危机、孩子上学等
- **40+**：孩子上学、中考、高考、青春期、更年期等

#### 生育意愿关键词
- **正面**：备孕、怀孕、宝宝、孩子、生育、想要孩子等
- **负面**：丁克、不生、不要孩子、不想生、讨厌小孩等
- **中性**：顺其自然、看情况、以后再说、不着急等

### 3. 算法优化

#### 特征提取逻辑
1. **文本预处理**：提取所有文本片段（bio、昵称、位置、帖子标题、内容等）
2. **关键词匹配**：使用关键词库进行匹配
3. **置信度计算**：根据匹配程度计算置信度
4. **证据收集**：收集支持判断的文本片段

#### 优先级处理
1. 生活阶段：优先识别生育状态（备孕/怀孕/已育）
2. 空间偏好：识别用户关注的空间要素
3. 收入水平：根据消费关键词判断
4. 年龄段：根据生活阶段关键词推断
5. 生育意愿：综合判断生育意愿

## 🔧 技术实现

### 1. 关键词库设计
- 使用字典结构存储关键词
- 支持多级分类
- 易于扩展和维护

### 2. 匹配算法
- 使用字符串包含匹配
- 支持大小写不敏感
- 收集匹配证据

### 3. 置信度计算
- 根据匹配关键词数量计算
- 考虑关键词权重
- 提供置信度阈值

## 📝 注意事项

1. **关键词覆盖**
   - 关键词库可能不完整
   - 需要根据实际情况扩展
   - 建议定期更新

2. **误识别风险**
   - 关键词匹配可能产生误识别
   - 建议结合 LLM 推断
   - 提供人工审核机制

3. **性能考虑**
   - 关键词匹配速度较快
   - 支持批量处理
   - 内存占用较低
