# 推断逻辑优化总结

## 📋 优化概述

本次优化对 `claw_map` 项目的推断逻辑进行了全面升级，通过增加交叉验证机制和优化推断算法，提升了生育意愿推断的准确性。

## 🎯 优化内容

### 1. 生活阶段推断优化

#### 优先级排序
1. **生育状态**（优先级最高）
   - 备孕中：备孕、排卵、验孕、造人
   - 怀孕中：怀孕、孕检、产检、胎动
   - 已育1孩：宝宝、婴儿、奶粉、辅食
   - 已育2孩+：大宝、二宝、三宝、俩娃

2. **婚姻状态**（次优先级）
   - 未婚：单身、一个人、独居、丁克
   - 已婚未育：结婚、老公、老婆、二人世界

#### 交叉验证
- 从生育状态推断年龄段
- 从婚姻状态推断生育意愿
- 优化关键词匹配逻辑

### 2. 年龄段推断优化

#### 关键词匹配
- 优先检查明确的年龄段关键词
- 从生育状态推断年龄段
- 从婚姻状态推断年龄段

#### 交叉验证
- 生育状态 → 年龄段
  * 备孕中/怀孕中/已育 → 30-34岁
  * 未婚/已婚未育 → 25-29岁

- 婚姻状态 → 年龄段
  * 未婚 → 25-29岁
  * 已婚未育 → 25-29岁

### 3. 生育意愿推断优化

#### 关键词匹配
- 正面意愿：备孕、怀孕、宝宝、孩子、生育
- 负面意愿：丁克、不生、不要孩子、讨厌小孩
- 中性意愿：顺其自然、看情况、以后再说

#### 交叉验证
- 生育状态 → 生育意愿
  * 备孕中/怀孕中 → 正面意愿（+3分）
  * 已育1孩/已育2孩+ → 正面意愿（+2分）
  * 未婚 → 中性意愿（+1分）
  * 已婚未育 → 中性意愿（+1分）

### 4. 空间偏好推断优化

#### 关键词匹配
- 通勤便利：地铁、通勤、上班、挤地铁
- 公园绿地：公园、遛娃、户外、旅行
- 医疗资源：医院、产检、儿科、看病
- 教育资源：幼儿园、小学、中学、学区
- 生活配套：超市、商场、买菜、生活
- 出行安全：安全、治安、监控、夜路
- 居住空间：房子、户型、面积、装修

#### 交叉验证
- 生育状态 → 空间偏好
  * 怀孕中/已育 → 医疗资源
  * 已育 → 教育资源
  * 未婚 → 公园绿地、居住空间

### 5. 消费水平推断优化

#### 关键词匹配
- 高收入：奢侈、高端、五星、名牌、豪华
- 低收入：平价、省钱、优惠、折扣、团购

#### 交叉验证
- 消费习惯 → 收入水平
- 生活方式 → 收入水平

## 🔍 问题分析

### 1. 宝妈日记识别失败

#### 问题
- 生活阶段：推断为"已育1孩"，预期为"已育2孩+"
- 年龄段：推断为"18-24"，预期为"30-34"

#### 原因
- "宝宝"被匹配为"已育1孩"，但实际应该是"已育2孩+"
- "毕业"被匹配为"18-24岁"，但实际应该是"30-34岁"

#### 改进方案
1. 优化"已育2孩+"的关键词匹配逻辑
2. 增加"大宝"、"二宝"等关键词的权重
3. 从生育状态推断年龄段

### 2. 职场女性识别失败

#### 问题
- 生育意愿：推断为"neutral"，预期为"unknown"

#### 原因
- "未婚"状态被推断为"中性意愿"
- 但实际应该是"未知意愿"

#### 改进方案
1. 优化未婚状态的生育意愿推断逻辑
2. 增加"未知意愿"的判断条件

### 3. 丁克一族识别失败

#### 问题
- 生育意愿：推断为"neutral"，预期为"negative"

#### 原因
- "丁克"被匹配为"未婚"
- 正面和负面信号数量相同

#### 改进方案
1. 优化"丁克"的关键词匹配逻辑
2. 增加"负面意愿"的权重
3. 从生育意愿推断生活阶段
